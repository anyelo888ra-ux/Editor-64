# 🍄 Editor 64

> Open-source web-based Super Mario 64 level editor and development studio inspired by the classic decompilation toolchains, running straight from your browser!

![Editor 64 Banner](https://img.shields.io/badge/Status-Active-brightgreen) ![License](https://img.shields.io/badge/License-MIT-blue) ![Platform](https://img.shields.io/badge/Platform-Web%20%2F%20Vercel-orange)

## 🚀 Overview

**Editor 64** is a lightweight, open-source tool designed for Super Mario 64 romhackers and developers. Create, modify, and preview custom levels, scripts, and assets without needing a heavy local setup. 

---

## ⚙️ Getting Started & Requirements

To use Editor 64 and build your custom levels, you will need a legal copy of the Super Mario 64 ROM (USA version). 

1. **Get the ROM:** You can download the required base ROM file here:
   👉 [Super Mario 64 (USA).z64 (via GitHub Source)](https://github.com/jb1361/Super-Mario-64-AI/blob/development/Super%20Mario%2064%20(USA).z64)
2. **Upload to Editor 64:** Drag and drop your `.z64` ROM into the web interface.
3. **Build & Play:** Start editing levels, writing scripts, and compiling straight inside your browser!

---

## 🛠️ Features

- 🌐 **100% Web-Based:** No complex installations required; runs smoothly in modern browsers.
- 🧱 **Custom Level Design:** Modular interface for placing objects, platforms, and modifying layouts.
- ⚡ **Open Source:** Contributions, pull requests, and forks are welcome to expand the ecosystem!

---

## 📦 Local Development

If you want to run Editor 64 locally on your machine:

```bash
# Clone the repository
git clone [https://github.com/tu-usuario/Editor-64.git](https://github.com/tu-usuario/Editor-64.git)

# Navigate to the project directory
cd Editor-64

# Install dependencies
npm install

# Run the development server
npm run dev

```
